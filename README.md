# Yizhe Hu

My interests connect mathematics, applied modelling and scientific computing with
statistical and machine-learning methods for reliable scientific inference.
I am developing this foundation toward Computational Biology through ongoing
research on biological pathway inference; unpublished methods and results remain private.

## Selected research software

1. [CPT–Vs modelling](https://github.com/49dj/cpt-vs-ml) — baseline scientific-ML
   workflow associated with a collaborative publication; public code only.
2. [Earth–Moon logistics](https://github.com/49dj/lunar-logistics-ress/tree/portfolio-cleanup)
   — collaborative MILP planning, reliability and sensitivity analysis; public V15 code.
3. [Thin-film inverse modelling](https://github.com/49dj/thin-film-inverse-modelling)
   — optical forward models and bounded numerical parameter estimation.
4. [Stair wear modelling](https://github.com/49dj/stair-wear-inference) — collaborative
   wear simulation and usage-profile fitting; a documented subset of the research.
5. [Indoor airflow simulator](https://github.com/49dj/indoor-airflow-simulator) — an
   interactive numerical prototype using fictional layouts.

Each repository states its scientific assumptions, collaboration context,
data-access limits and verified software scope.
